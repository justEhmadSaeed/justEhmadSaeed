I am a **Senior Software Engineer** building product infrastructure at **[Ignite Visibility](https://ignitevisibility.com/)** and **[Purpose Brands](https://www.purposebrands.com/)**. My work spans frontend architecture, robust backend systems, APIs, and practical AI integrations—shipping maintainable systems, improving reliability and speed, and turning complex requirements into software that teams can operate with confidence.

- **Focus Areas:** High-Performance Web Applications, API Architecture, LLM/AI Workflows, and Cloud Infrastructure.

- **Engineering Philosophy:** Code should be highly readable, deeply reliable, and built to solve real user problems.
